Unitarias + mutación

Cobertura 93 %, mutación 61 %: la cobertura sola engaña

Qué prueban las unitarias

Comparadores semver y PEP 440, parsers de package-lock v1–v3 y requirements.txt, CVSS, deduplicación, versión segura y la lógica de la extensión. Sin red: dobles de prueba de OSV.

Qué es la mutación (Stryker)

Stryker cambia el código a propósito (un < por <=, un && por ||) y vuelve a correr las pruebas. Si ninguna falla, el mutante sobrevive: esa línea se ejecuta pero nadie verifica su resultado.

Integración y sistema

De las piezas juntas al sistema completo

Integración · 26 pruebas

  • API Fastify + SQLite + sesiones + OAuth de GitHub ensamblados (app.inject).
  • Clientes HTTP reales de OSV y registros contra un OSV local: todo en un lote, la caché evita repetir consultas, reintento ante 503.
  • Telemetría, logs, sesiones e historial (no-funcionales.test.ts).

Sistema · 23 pruebas

  • DepScan compilado corriendo como proceso; solo se le habla por HTTP.
  • Flujo completo: escanear → solución → historial → HTML/PDF → borrar.
  • El historial sobrevive a un reinicio del servidor.
  • Rate limit (429), cabeceras de seguridad, X-Request-Id y log del escaneo.
  • La CLI: --help, errores y path traversal en --output.
Interfaz de usuario · Playwright

Un navegador real, en escritorio y en móvil

  • 8 pruebas × 2 dispositivos (Chrome de escritorio y Pixel 7).
  • Subir manifiestos, ver hallazgos, abrir la solución, filtrar, descargar, borrar del historial, página Estado.
  • Cada prueba graba video, traza paso a paso y captura.
  • En el reporte: View trace repite la prueba con el DOM de cada paso.

Reto · cómo se hizo, cómo se descarga y cómo vive en el repo

Del código al .vsix, automáticamente

1 · Cómo se hizo

  • apps/vscode/: un workspace más del monorepo.
  • esbuild empaqueta el core dentro: el .vsix pesa 40 KB y no trae dependencias.
  • src/: extension · controlador · proveedores · agente · motor · manifiestos.
  • 17 unitarias + 8 e2e en un VS Code real (@vscode/test-electron).

2 · Cómo se descarga e instala

  • Panel → /extension → Descargar depscan.vsix.
  • code --install-extension depscan.vsix
  • o Extensiones → ⋯ → Instalar desde VSIX…
  • VS Code 1.99+; preguntas libres al agente con Copilot.

3 · Cómo está en git

  • Job Extensión VS Code (e2e + .vsix) en pruebas.yml.
  • VS Code corre en pantalla virtual (xvfb-run).
  • Empaqueta con vsce y lo publica en GitHub Pages.
  • Docs: docs/RETO_VSCODE.md · apps/vscode/README.md
